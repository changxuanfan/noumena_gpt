# AI-assisted development process

This repository follows the workflow required by the assignment:

1. Install `mattpocock/skills` into the repository.
2. Run `setup-matt-pocock-skills` with GitHub Issues.
3. Start routing from `ask-matt`.
4. Use `grill-with-docs` to resolve vocabulary and durable decisions.
5. Use `to-spec` to synthesize the agreed feature.
6. Use `to-tickets` to publish dependency-aware vertical slices.
7. Implement each ticket test-first and review it before merge.

The project uses GitHub Copilot CLI runtime in VS Code. Every pull request
records the actual model, AI-assisted work, test evidence, and consequential
human decisions.
